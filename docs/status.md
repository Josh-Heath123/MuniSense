## Known limitations

- Built so far: the pure domain; database settings, roles and connections (`platform`, `persistence`, P2-3); canonical JSON, publications, source manifests and drafts (`provenance`, P2-4, P2-6); the supplier catalogue (`catalogue`, P2-6); the citation check, the publish step and the publication guards (`ingestion`, P2-7 to P2-9); and the `services.demo` entry point, which reads published data through the repository (P2-13). `api`, `console` and `mcp` are still empty modules, so their 100% coverage is vacuous.
- `calculate_bill` prices one calendar month (or, without monthly values, any period inside one version, season and VAT rate); anything else goes through `calculate_period`, which splits and pro-rates by an `estimated` billing policy (ADR-0011).
- Every hook has been seen firing on chosen examples inside WSL (P0-7). They are best-effort controls with known gaps (security document, TD-1 to TD-3, TD-8, TD-9).
- CI is a merge gate since E52: a GitHub ruleset on `main` requires a pull request and the green "verify and audit" check, and blocks force pushes and deletion. It runs the pull request's own code, so a pull request that changes CI or the guards could still weaken them; the owner's review (0 approvals required, so a working rule) and the data-only rule for publications are the controls.
- PostgreSQL runs locally and in CI from the same image digest; the test connection variable `MUNISENSE_TEST_DATABASE_URL`, the user `munisense` and the database `munisense_test` match, while CI has no development database and its own throwaway password. No test connects to it yet; database tests and a driver dependency arrive in P2.
- pre-commit hooks must be installed once per clone: `uv run pre-commit install`. Committing needs Docker running (the gitleaks hook blocks the commit otherwise), and the gitleaks hook does not work in a `git worktree`. Docker's Windows credential helper (`credsStore: desktop.exe`) failed once when pre-commit pulled the gitleaks image; a plain `docker pull` of the same pinned image worked.
- The pre-push hook does not catch deleting `main`, multi-ref pushes or pushes with a stale view of `main` (TD-9, accepted by the owner); the owner's review of merges and CI remain the controls.
- In CI, the large-file check checks nothing (it looks at staged files only).
- The local database starts with Docker Desktop (`restart: unless-stopped`) until it is stopped with `docker compose stop db`.
- `ubuntu-latest` is now Ubuntu 26.04, while development runs on Ubuntu 24.04. uv supplies CPython 3.13 on both (the patch level may differ).
- The tariff facts in `domain/sa-tariffs.md` come from desk research and are not yet verified against primary documents.
